## How the data refreshes

GitHub's hosted runners **cannot reach the Tamil Nadu board endpoints**: every fetch fails from
their US egress (verified in the run logs — `tnpsc.gov.in`, `trb.tn.gov.in` all fail). A scheduled
GitHub Action therefore cannot keep the data fresh, so the schedule is disabled and the refresh runs
on this Mac:

- Launch agent: `~/Library/LaunchAgents/in.examlens.refresh.plist`
- Script: `scripts/deploy-local.sh`
- Schedule: 08:10 and 20:10 local time, every day
- Log: `~/Library/Logs/examlens-refresh.log`

The script runs `pnpm refresh`, `pnpm validate`, `pnpm build`, then deploys `dist/` to Netlify.
A validation failure still deploys the data (so the "source changed" flag reaches readers) and is
recorded in the log.

### Manual run

```bash
launchctl kickstart -k gui/$(id -u)/in.examlens.refresh
# or
./scripts/deploy-local.sh
```

### Installing on another machine

```bash
mkdir -p ~/.config/examlens
printf '%s' '<netlify-token>' > ~/.config/examlens/netlify-token
chmod 600 ~/.config/examlens/netlify-token
cp deploy/in.examlens.refresh.plist ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/in.examlens.refresh.plist
```

The plist hard-codes the project path; edit it if the repo moves.

## Domain

The site is on the free `examlens-tn.netlify.app` subdomain. A free *custom* domain was attempted:

- **DuckDNS** — requires completing a reCAPTCHA to create the subdomain. Not completed.
- **is-a.dev** — its repository asks that requests are not generated by an AI; a request was not
  submitted on your behalf.

To attach a domain later: Netlify → Domain management → Add a domain, then point DNS at the site
(CNAME to `examlens-tn.netlify.app`). After changing the domain, rebuild with
`SITE_URL=https://your.domain pnpm build` and redeploy so canonical URLs follow.

### If you want `examlens.is-a.dev`

Fork `is-a-dev/register`, add `domains/examlens.json` following https://docs.is-a.dev, and open the
pull request yourself. Once merged:

```bash
SITE_URL=https://examlens.is-a.dev pnpm build
npx netlify-cli deploy --prod --dir=dist --site 6d48c4a4-9c68-47f0-bce3-836bf7820493
```

Then add `examlens.is-a.dev` in Netlify → Domain management.
